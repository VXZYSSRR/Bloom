    Transfers

    Required: files you receive are saved here and seeded from here

    Where supported, received files are written progressively to this folder instead of being held in memory.

    Files you request from the same person are queued in this order. You can still move any waiting file on the Downloads tab.

    Verified only keeps your listing between devices you've verified. A slot frees after 60 s without progress. A listing stays open until you stop sharing. Upload speed is shared between downloaders.

    Files you have received stay on offer to others who want the same file, only while Bloom is open, and are marked “Seeding” in Downloads. Seeding follows the “Relay to” setting under Advanced.

    Seeded files show up in Open downloads so people can still find them when whoever first shared them is offline. They are listed to the same people as your other listings (Sharing → Who can see listings) and follow “Relay to” under Advanced. Anyone who requests one connects to you and can see your IP address.

    Downloads pull different pieces from several people at once and check every piece against a signed hash. With relaying on, a finished download is kept in browser storage and offered to others, and pieces you are still fetching are shared too, but only while this tab stays open. Everyone you serve, and every peer you connect to, can see your IP address. Uploads use the “Max simultaneous downloads” limit under Sharing. Downloads that finish while relaying is off are not kept.

    Export saves your trusted devices and settings to a file.

    Exports hold trusted public keys, labels and settings — never your private key. Clearing browser storage makes you a new device. Only import files you exported yourself.

    Sharing

    When a device you can see is on a newer Bloom, your copy fetches it straight from them, and yours is sent to anyone on an older one. Connections are tied to each device's key. Bloom cannot replace itself: you get an "Update ready" card, save the file and open it yourself. Only install updates from people you trust, since the file is theirs. Whoever sends or receives can see your IP address.

    A check fetches one small version file from the update address, so that host can see your IP address. Nothing about your files, devices or settings is sent. Bloom never installs anything itself.

    These are tuning options. The defaults work for almost everyone, so you only need to change them if something is not working on your network.

    Transfers

    Adaptive adjusts chunk size and backpressure to the browser's negotiated limits. Larger isn't always faster.

    Relay to decides who may fetch pieces from you while relaying is on (Settings → Seeding & relaying).

    Computers and phones that go to sleep stop transfers. Bloom asks the browser to stay awake only while something is actually moving. If the page does sleep or reload, unfinished downloads pick up where they stopped.

    Discovery relays
    Not connected. Relays are tried when you go online.

    Bloom connects to every relay in this list at the same time and uses whichever ones your network lets through, so two devices only need one relay in common. One address per line, starting with wss:// (a private broker can be written as wss://user:password@host:port/path). ws:// addresses (no encryption) are included as a last resort for networks that only allow port 80; they only work when this file is opened from your computer or an http:// page. Changes apply the next time you go online. Relays only see small signed discovery messages, never your files.
